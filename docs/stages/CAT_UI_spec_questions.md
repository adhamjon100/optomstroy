# Экран выбора товаров (SCR-10/11/12) — вопросы и пробелы ТЗ, найденные при доработке по замечаниям заказчика

Файл ведут агенты доработки экрана каталога (замечания заказчика 2026-10-28: макет, «мигает весь экран при смене категории»). Каждый агент добавляет свой раздел, только добавлением. Формат пункта: ID `CQ-<агент>-NN`, документ и параграф, суть, принятое временное решение. `docs/specification/**` и `contracts/**` не правятся.
