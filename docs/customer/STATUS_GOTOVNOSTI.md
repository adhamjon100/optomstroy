# Что готово, что нет и что дальше

**Оптомстрой POS · состояние на 20.11.2026**

**Что изменилось 20.11.2026.** Вы отменили работу без 1С и ночной обмен (это наш пересказ, а не цитата). Возвращаемся к утверждённому ТЗ: 1С — главная система. Сервер POS связан с 1С круглосуточно. Заказы, оплаты и возвраты сразу уходят в 1С; если 1С недоступна, они копятся на сервере и уходят позже. Товары, цены и остатки берутся из 1С. Начатую работу без 1С мы сохранили в архиве. Просим подтвердить отмену письменно — вопрос 125 в «Вопросах заказчику».

К запуску в магазине пока не готово. Сервер, который вы прислали, по мощности подходит с большим запасом — это по присланным данным; подтвердим проверкой (у виртуального сервера ядер может быть меньше). Не хватает:

- доработки 1С (API) от вашего программиста по «Требованиям к API 1С»: без неё магазин не работает, потому что 1С — главная система;
- тестовой копии базы 1С с публикацией, на которой проверим доработку;
- решения, где хранить настоящие данные (предложенный сервер — в Германии), и заключения юриста;
- второго диска для резервных копий;
- ваших сведений о сервере и письменного разрешения на работы на нём.

## Готово

- **Программа для касс и продавцов:** продажи, оплаты, долги, возвраты, каталог, вход по SMS, по PIN и по лицу. Написана и проверена автоматическими тестами — пока с имитатором 1С (нашей программой, которая изображает 1С). Установочных пакетов для Windows и Android ещё нет; на ваших устройствах программа не проверялась.
- **Планшет в зале** — так же: написан и проверен автоматическими тестами, на устройстве не проверялся.
- **Серверная часть и набор для установки:** установка, обновление с возможностью вернуть прошлую версию, ежедневная и непрерывная копия, восстановление, наблюдение за работой. Связь с 1С через очередь: если 1С недоступна, заказы и оплаты ждут и уходят позже. Проверены без настоящего запуска и без настоящей 1С; первый запуск на настоящем сервере — впереди.
- **Задание программисту 1С:** «Требования к API 1С» (версия 1.2.1 от 20.11.2026; требования — те же, что в версии 1.2), контракт обмена версии 1.2.0 и образцы данных.
- **Требования к серверу**, версия 1.5 — с оценкой присланного вами сервера во Франкфурте и с работой 1С круглосуточно.
- **Веб-демо** для показа; последние исправления в нём ещё вносятся.

## Ещё не готово

- **Доработка 1С (API)** — делает ваш программист 1С по «Требованиям к API 1С». Пока её нет, программа работает только с имитатором 1С.
- **Программа проверки API 1С** — для вашего программиста: сама вызывает методы 1С на тестовой копии базы и сверяет ответы. Переделываем её под «Требования к API 1С» версии 1.2.1. Пришлём программисту, когда закончим.
- **Обмен с вашей 1С в течение дня** — ждёт доработку 1С. Проверим сначала на тестовой копии базы, потом включим на рабочей по вашему «да».
- **Установочные пакеты для касс** с адресом вашего сервера — нужны домен магазина и сборка.
- **Проверка на ваших устройствах:** компьютеры касс, планшет, телефоны.
- **Первый запуск набора установки на настоящем сервере.**
