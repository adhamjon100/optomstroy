# Оптомстрой POS — веб-демо: инструкция для заказчика

Адрес: **https://optomstroy-demo-4fhvb.netlify.app**

**Пометка (временная, до следующего обновления сайта):** вставка правой кнопкой мыши → «Вставить» в полях входа, возврат курсора в поле после панели «ДЕМО» и значки у подразделов без картинки работают в сборке новее `52c710aee3125846`. Сейчас на сайте щёлкните в поле и нажмите Ctrl+V. Вход по лицу или отпечатку (раздел «Вход по лицу или отпечатку» ниже) тоже появится только после обновления сайта.

Это демо-версия «Оптомстрой POS» для просмотра в браузере. Её задача — показать продукт, чтобы вы могли его попробовать и написать замечания.

## Что важно знать сначала

- **Все данные тестовые:** товары, цены, клиенты, долги и заказы придуманы.
- **1С, SMS и банк не подключены.** Их заменяют имитаторы, которые отвечают так же, как будут отвечать настоящие системы.
- **Логика сервера настоящая.** Работает тот же серверный код, что будет на сервере магазина: те же правила долга, скидок, статусов заказа и прав ролей.
- **Браузер — не рабочая платформа продукта.** Рабочие места в магазине — кассы на Windows и устройства на Android. Браузер нужен только для показа. Особенности браузера, описанные ниже, — не дефекты продукта.

## Как открыть

1. Откройте ссылку в **Chrome** или **Edge** на компьютере, в **одной** вкладке.
2. Первая загрузка может занять до минуты: браузер загружает приложение и базу данных (около 11–25 МБ). Повторные заходы быстрее. Демо занимает в браузере около 0,6–0,8 ГБ памяти; если компьютер работает медленно, закройте лишние вкладки и программы.
3. Не открывайте ссылку на телефоне и из Telegram или WhatsApp. На телефоне демо покажет «Откройте на компьютере в Chrome или Edge». Кнопка «Всё равно продолжить» есть, но работа на телефоне не гарантирована. Исключение — проверка входа по лицу или отпечатку на телефоне Android (раздел ниже): откройте ссылку в Chrome и нажмите «Всё равно продолжить».

## Как войти

Нажмите кнопку **«ДЕМО»** у правого края экрана внизу и откройте «Как войти»: там код и список номеров с кнопками «Скопировать номер». Код из SMS всегда один: **246810**. Скопированный номер вставляется в поле «Номер телефона» клавишами Ctrl+V или правой кнопкой мыши → «Вставить»: если перед открытием «ДЕМО» курсор стоял в поле, после закрытия панели он вернётся туда. Так же вставляется и код.

Вход: в поле «Номер телефона» введите 9 цифр после +996 → «Получить код» → на экране «Введите код из SMS» — 246810.

Если в браузере включено чтение с экрана (экранный диктор) или специальные возможности, поле кода может не принимать цифры. Это известная особенность веб-демо: выключите чтение с экрана и обновите страницу.

- **Сотрудник** при первом входе сам придумывает **PIN из 6 цифр**, например 715382, и вводит его дважды на экране «Задайте PIN-код для работы», затем отмечает «Я ознакомлен(а) с условиями обработки персональных данных» и нажимает «Начать работу». Простые PIN вроде 111111 или 123456 не подойдут.
- **Покупатель** при первом входе заполняет короткую анкету «Расскажите о себе» (ФИО, год рождения, отметка «Я ознакомлен(а)…» → «Продолжить») и задаёт PIN из 4 цифр.
- Тексты согласий — проект: поля в угловых скобках (`<полное наименование магазина, ИНН…>`, `<N>`) заполнит юрист магазина.

## Вход по лицу или отпечатку

Демо показывает вход по лицу или отпечатку через ключ доступа браузера (passkey). Каждый пользователь включает его сам.

1. Войдите по номеру и коду 246810.
2. Откройте «Настройки» → «Защита входа». «Настройки» есть в меню профиля в шапке и в «Профиле».
3. Включите переключатель:
   - на компьютере с Windows — «Вход через Windows Hello». Если браузер не умеет вход без PIN, переключатель называется «Windows Hello перед вводом PIN» (о нём ниже);
   - на телефоне Android и в других системах — «Вход по отпечатку или лицу».

   Если появится «Согласие на вход по биометрии», отметьте «Согласен» → «Включить». Если приложение попросит подтвердить действие, введите PIN или код 246810.
4. Браузер попросит подтвердить вход лицом, отпечатком или PIN устройства и сохранит ключ доступа для этого сайта.
5. Проверьте: обновите страницу (F5). На Windows нажмите «Войти через Windows Hello» и посмотрите в камеру — откроется рабочий экран без PIN приложения. На телефоне окно браузера для лица или отпечатка откроется само, PIN приложения не нужен.

Что важно знать:

- **Windows.** Лицо работает, только если у компьютера есть камера с поддержкой Windows Hello (инфракрасная). Без неё Windows предложит отпечаток или PIN Windows.
- **Если браузер не умеет вход без PIN**, приложение покажет «Браузер не поддерживает вход без PIN. Windows Hello включён перед вводом PIN». Тогда на экране входа: «Windows Hello» → лицо → PIN приложения. Это ограничение браузера, а не приложения для Windows.
- **Телефон Android.** PIN приложения не нужен. Вместо лица телефон может предложить отпечаток или PIN телефона: упрощённое распознавание лица браузер, скорее всего, не использует.
- **Адрес сайта.** Ключ доступа работает только на том адресе, где его включили. Открывайте демо по основному адресу optomstroy-demo-4fhvb.netlify.app. На другом адресе вход по лицу нужно включать заново.
- **Сброс.** «Сбросить демо» выключает вход по лицу в демо, но сам ключ доступа может остаться в Windows или в Google. Его можно удалить вручную: в Windows 11 — «Параметры» → «Учётные записи» → «Ключи доступа», на Android — в менеджере паролей Google.
- **Если ключ доступа удалён** в Windows или в Google, а вход по лицу в демо ещё включён, окно Windows Hello или браузера закроется как отмена — войдите по PIN. На телефоне выключите и снова включите вход в «Защите входа». На Windows вход по лицу снова включается только после «Сбросить демо».
- **Планшет магазина** вход по лицу не предлагает — так задумано.

Ищите по имени из таблицы или по полному номеру. По последним 4 цифрам (0102 и т. п.) находятся ещё и обычные тестовые клиенты: «0102» есть и в номере «Клиент 20 (тест)» +996 700 001 020.

## Что попробовать

1. **Продавец, оплата по QR** (902). Каталог → поиск → «+ Добавить» → кнопка «Корзина» в шапке → «Создать заказ · F9». В окне «Подтверждение заказа» выберите «Самовывоз» и «QR / карта Бакай Банк» → «Создать заказ и показать QR». Оплата подтверждается сама примерно через 20 секунд или кнопкой «Оплатить сейчас» в «ДЕМО» → «Оплата QR»; приложение покажет «Оплата получена» и через несколько секунд само откроет страницу заказа (если окно «Заказ создан» ещё открыто — «Открыть заказ»). Товарный чек с предпросмотром: на странице заказа «Документы» → «Товарный чек» → «Просмотр»; окно предпросмотра закрывается кнопкой «Закрыть» (в окне «Заказ создан» у чека есть только «Печать» — она сразу открывает печать браузера). «Счёт на оплату» отмечен в «Печать после создания заказа», поэтому окно печати браузера откроется само, когда придёт номер «1С»; его можно закрыть.
2. **Кассир, продажа в долг запрещена** (906). Клиенты → «Просрочка» → «В заказ» → товар «+ Добавить» → кнопка «Корзина» → «Создать заказ · F9» → «Без оплаты / долг». Приложение покажет причину отказа «Есть просроченная задолженность» и подсказку «Как получить разрешение старшего». Тот же заказ можно создать за наличные: «Наличными в кассу» → «Создать заказ» → «Принять оплату» → на экране «Приём оплаты» «Без сдачи» (или сумма в поле «Получено от клиента») → «Принять … сом» → «Подтвердить приём» → «Принято … сом» (при отметке «Товарный чек» браузер откроет окно печати чека — его можно закрыть).
3. **Старший продавец, разрешение продажи в долг** (907). Тот же клиент → «Создать заказ · F9» → «Без оплаты / долг» → «Разрешить продажу в долг» → причина и PIN → «Создать заказ в долг». Если кнопки «Разрешить продажу в долг» не видно, прокрутите окно оформления вниз.
4. **Покупатель, заявка** (905). Регистрация (анкета «Расскажите о себе», PIN из 4 цифр дважды) → каталог → «+ Добавить» → «Корзина» → «Отправить заявку» → в окне «Подтверждение заказа» снова «Отправить заявку» → «Мои заказы»: заявка в списке. С номером +996 700 000 101 после той же регистрации приложение покажет «Мы нашли вашу карточку клиента» → «Да, это я»; после этого покупатель видит свой долг в «Профиле».
5. **Администратор, пользователи и аудит** (901). Меню разделов («☰») → «Администратор» → экран «Пользователи» → «+ Пригласить»: пригласите сотрудника на +996 777 000 904 (роль, подтверждение своим PIN) и войдите с этим номером — приложение покажет «Вы вошли по приглашению администратора» и попросит задать PIN. Журнал действий — «Журнал аудита» в меню разделов; после сценария 3 там видна запись «Разрешена продажа в долг».
6. **Руководитель, отчёты** (909). Первый экран — «Отчёты»: продажи за сегодня, средний чек, оплаты по способам, долги клиентов. Цифры учитывают заказы предыдущих сценариев.
7. **Работа без сети.** В «ДЕМО» → «Сеть» включите «Нет сети (имитация)». Приложение покажет «Нет сети. Показаны данные от ЧЧ:ММ. Заказы недоступны»: каталог открывается из памяти, изменения корзины уйдут на сервер, когда сеть вернётся. Выключите отметку — баннер пропадёт.
8. **Планшет магазина** (901, затем покупатель в зале). Это режим для торгового зала: покупатель сам выбирает товары на планшете и отправляет заявку, оплачивает на кассе. Те же шаги — в «ДЕМО» → «Планшет магазина». После подключения вкладка работает как планшет; вернуться к обычному входу и обратно можно кнопками «ДЕМО» (шаги 6–7).
   1. Войдите администратором +996 777 000 901, код 246810. При первом входе задайте PIN, например 715382.
   2. Меню разделов («☰») → «Администратор» → в шапке экрана «Пользователи» кнопка разделов (подсказка «Ещё») → «Планшеты магазина».
   3. «Сделать это устройство планшетом магазина» → имя, например «Планшет у входа»; склад уже выбран → «Сделать это устройство планшетом магазина» → подтвердите своим PIN.
   4. Появится аварийный код выхода, он показывается один раз. В демо его можно не записывать: кассиром в этой же вкладке можно войти через «ДЕМО» (шаг 6). «Готово» — откроется витрина планшета: каталог без входа и меню сотрудника, с пометкой «Обычные цены магазина».
   5. Заявка: «+ Добавить» на карточке товара (или нажмите на товар → «В корзину · …») → кнопка корзины в шапке → «Оформить заявку» → номер на экранной клавиатуре, например 700 000 101 (покупатель с карточкой «1С») или любой другой → «Получить код» → 246810 → «Отправить заявку». Появится «Заявка № … отправлена». «Готово» очищает корзину для следующего покупателя.
   6. Заявка видна в «ДЕМО» → «1С» с пометкой «С планшета». Кассир (+996 777 000 906) видит её в «Ожидают оплаты» с той же пометкой. Чтобы войти кассиром в этой же вкладке: «ДЕМО» → «Планшет магазина» → «Вернуться к обычному входу». Страница перезагрузится и откроет экран входа — войдите номером кассира.
   7. Вернуть планшет: «ДЕМО» → «Планшет магазина» → кнопка «Планшет магазина». Откроется тот же планшет, подключать заново не нужно, корзина планшета пуста. Вход кассира тоже сохранится: следующее «Вернуться к обычному входу» откроет его без кода из SMS, по PIN.
   8. Если «Планшет магазина» не смог вернуть планшет (данные браузера очищены или повреждены) или витрина просит подключить планшет заново, «ДЕМО» предложит «Подключить этот браузер заново». Затем войдите администратором → «Планшеты магазина» → «Подключить заново этот планшет» → выберите планшет → PIN. Это тот же планшет: история заявок сохраняется, аварийный код — новый.

   На планшете в магазине кнопки «ДЕМО» нет. Там выход — только у администратора: удержание логотипа «Оптомстрой» на витрине 5 секунд → аварийный код → «Выйти из режима планшета». После такого выхода планшет подключают заново (шаг 8 без «ДЕМО»). В демо этот путь тоже работает.

Чтобы проверить «продавец оформил → кассир принял оплату», выйдите и войдите другим номером **в той же вкладке**.

## Что в демо работает не так, как в настоящей системе

- **Остатки и долги после продаж не меняются.** В настоящей системе их пересчитывает 1С и присылает приложению. Имитатор 1С этого не делает.
- **QR-код не настоящий:** банковское приложение его не примет. Оплата подтверждается сама или кнопкой в «ДЕМО».
- **Данные хранятся только в этом браузере на этом компьютере.** Другой компьютер, другой браузер или окно инкогнито — это отдельное пустое демо.
- **Демо работает в одной вкладке.** Во второй вкладке появится «Демо уже открыто в другой вкладке» и кнопка «Продолжить здесь».
- **Сброс.** «ДЕМО» → «Сервис» → «Сбросить демо» → «Сбросить» начинает всё заново. После обновления сайта ваши данные обычно сохраняются. Если изменилось устройство данных, демо предупредит и начнёт заново.
- **Фоновые операции** (подтверждение QR, отправка заказов в «1С», обновление данных) идут, только пока вкладка открыта. Когда вы снова откроете демо, они продолжатся.
- **Нет камеры-сканера и печати на чековый принтер.** Чеки и накладные открываются как PDF, печать — через браузер.
- **Вход по лицу или отпечатку в демо — только показ.** Ключ доступа браузера показывает, как работает вход, но данные демо не защищает: всё хранится в этом же браузере. В приложениях для Windows и Android вход по лицу устроен иначе. На Windows ключ Windows Hello хранится в защищённом модуле компьютера. На рабочем сервере вход по лицу включат после проверки на ваших компьютере и телефонах.
- **Вход через Windows Hello без PIN в демо разрешён всем.** В магазине он будет работать, только если на этом компьютере в приложение входит один человек. Если на кассе по очереди работают несколько сотрудников, приложение предложит Windows Hello перед вводом PIN. Разрешить вход без PIN всем можно только письменным решением.
- **Номера заказов идут с пропусками** (например, после POS-2026-000035 сразу POS-2026-000067), если страницу обновляли или закрывали. Заказы не потеряны: база в браузере при обновлении страницы не закрывается штатно и пропускает заранее выделенные номера. На сервере магазина пропуски номеров тоже возможны (после сбоя), номера остаются уникальными.
- В списке сотрудников и в журнале есть учётки **«Демо-история»**. Они создали историю заказов при первом запуске, войти под ними нельзя.
- **Планшет магазина в браузере** (сценарий 8):
  - приложение не закрепляется на экране. На планшете Android в магазине закрепление обязательно: покупатель не сможет выйти из приложения;
  - повторный код из SMS можно запросить через 10 секунд, а не через 60, как в магазине;
  - оповещение «планшет не на связи» в демо выключено;
  - переключение «Вернуться к обычному входу» / «Планшет магазина» есть только в демо. «ДЕМО» переносит данные приложения в хранилище этой страницы и перезагружает её. Перед переключением витрина очищается, как при гашении экрана планшета;

## Особенности браузера (это не дефекты продукта)

- **Ctrl+1…5** (разделы), **F5** и **Ctrl+R** работают в приложении, когда оно в фокусе (щёлкните по приложению). F5 обновляет список на экранах с кнопкой «Обновить», Ctrl+R на экране «Синхронизация с 1С» запускает синхронизацию. На остальных экранах F5 и Ctrl+R перезагружают страницу: вы останетесь в системе — приложение попросит PIN и вернёт на тот же экран, корзина и заказы сохраняются.
- **Ctrl+N, Ctrl+T, Ctrl+W и Ctrl+Shift+N** браузер приложению не отдаёт: новое окно, новая вкладка, закрыть вкладку, окно инкогнито (в нём — отдельное пустое демо). В приложении на кассе Windows Ctrl+N («Пригласить», «Новый клиент») и Ctrl+Shift+N («Уведомления») работают. В демо пользуйтесь кнопками приложения.
- **Кнопка «Назад» браузера** листает страницы мимо вопросов приложения вроде «Выйти без сохранения?». Пользуйтесь кнопками приложения.
- **Правая кнопка мыши** открывает меню приложения, а над полем ввода, в котором стоит курсор, — меню браузера с «Вставить». Копировать и вставлять можно и клавишами Ctrl+C и Ctrl+V. Если браузер не разрешил вставку, приложение подскажет: «Браузер не разрешил вставку из буфера обмена. Нажмите Ctrl+V (на Mac — ⌘V) или откройте меню в самом поле».
- **Safari, iPad и телефоны** — по возможности. Safari удаляет данные сайта, если на него не заходить 7 дней.
