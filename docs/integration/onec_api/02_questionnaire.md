# Анкета: что нам нужно знать о вашей 1С

Пожалуйста, ответьте на анкету **до начала разработки**: от ответов зависят имена объектов во всех методах. Отвечайте простым текстом или скриншотами. Если вопрос к вам не относится, напишите «не используется».

Пункты, отмеченные «на тестовой копии», проверяйте только на копии базы, не в рабочей.

**Вместе с ответами пришлите:**

1. Скриншот окна «О программе»: кнопка «i» или «Сервис и настройки → О программе».
2. Выгрузку `$metadata` стандартного OData — файл XML, который начинается с `<edmx:Edmx`. Если OData не публикуется, пришлите список объектов из Конфигуратора по разделу «Объекты учёта» этой анкеты.
3. Обезличенные образцы данных (Q-040: образцы данных 1С):
  - 50–100 карточек номенклатуры с характеристиками;
  - прайс;
  - остатки;
  - 10–20 клиентов без реальных имён и телефонов.
4. Перечни значений перечислений, которые использует POS:
  - статусы заказов клиентов;
  - состояния выполнения заказа;
  - статусы заявок на возврат;
  - хозяйственные операции платёжных документов.
