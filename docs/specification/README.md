## Правила внесения изменений

1. Канонические имена, решения и границы задаёт ядро R0; документ ТЗ ему не противоречит. Несогласие автор записывает в раздел «Замечания к ядру» своего документа и продолжает следовать ядру.
2. У каждого документа один владелец; правка чужого документа — только через владельца.
