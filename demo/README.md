# Оптомстрой POS — демо на этом компьютере

## Что это

Демо работает целиком на одном компьютере с Windows: приложение для магазина и сервер к нему.

- Все данные **тестовые**: 500 товаров с ценами и фото, клиенты, долги, заказы.
- **Реальной 1С нет.** Вместо неё работает имитатор: он отвечает так же, как будет отвечать 1С (номера документов, остатки, долги, подтверждение оплаты).
- **SMS не отправляются.** Код из SMS в демо всегда один: **246810** — для **любого** номера +996, в том числе вашего. Этот код действует только в локальном демо-режиме и в настоящей системе не работает.
- **Банка нет.** Оплата по QR в демо подтверждается сама примерно через 10–20 секунд.
- При каждом запуске данные создаются заново. Всё, что вы сделали в прошлый раз (заказы, клиенты, PIN), не сохраняется.

## Веб-демо (в браузере, без установки)

То же приложение можно открыть в браузере, без Node.js и без сборки: сайт Netlify `optomstroy-demo-4fhvb`, адрес появится после выкладки (её выполняет пользователь — `demo/web/README.md` «Выкладка»). Сервер и база работают прямо в браузере, данные тестовые, 1С, SMS и банк заменены имитаторами.

- Откройте ссылку в Chrome или Edge на компьютере, в **одной** вкладке. Первая загрузка может занять до минуты.
- Вход: номер из кнопки «ДЕМО» у правого края экрана («Как войти» → «Скопировать номер») и код **246810**. Сотрудники — те же номера +996 777 000 901…909, что в таблице «Учётные записи»; +996 700 000 101 — покупатель с карточкой 1С («Покупатель Долг в лимите (тест)»).
- Сценарии — как в разделе «Что попробовать» ниже, но с клиентами веб-демо; пошагово для браузера — `docs/customer/WEB_DEMO_INSTRUCTION.md` «Что попробовать». Оплата по QR подтверждается сама примерно через 20 секунд или кнопкой «Оплатить сейчас» в «ДЕМО» → «Оплата QR»; вместо отключения Wi-Fi — «ДЕМО» → «Сеть» → «Нет сети (имитация)». После F5 приложение просит PIN и возвращает на тот же экран.
- Тестовые клиенты в веб-демо называются иначе, чем здесь: «Покупатель Просрочка (тест)» +996 700 000 102, «Покупатель Долг в лимите (тест)» +996 700 000 101 (у него есть карточка в 1С), «ОсОО Лимит превышен (тест)» +996 700 000 104, «ОсОО Без долга (тест)» +996 700 000 103. Кассир, старший продавец, администратор и руководитель ищут их по имени («Просрочка», «Долг в лимите», «Лимит превышен», «Без долга») или по полному номеру. Продавец ищет только по полному номеру, например +996 700 000 102: так задумано (ядро §19.4). По последним 4 цифрам находятся и обычные клиенты («0102» — ещё и «Клиент 20 (тест)» +996 700 001 020), поэтому ищите по имени.
- Остатки и долги после продаж в демо не меняются: в настоящей системе их пересчитывает 1С.
- Всё сохраняется только в этом браузере. «ДЕМО» → «Сервис» → «Сбросить демо» → «Сбросить» начинает заново.
- Браузер — не рабочая платформа продукта (рабочие места — Windows и Android). Особенности браузера (горячие клавиши, кнопка «Назад», меню по правой кнопке) — не дефекты продукта.

Инструкция для заказчика — `docs/customer/WEB_DEMO_INSTRUCTION.md`, ограничения — `docs/known_issues.md` §7а, решение — ТЗ 15 ADR-113. Сборка, проверка и выкладка сайта (для программиста) — `demo/web/README.md`; устройство бэкенда в браузере — `demo/web/backend/README.md`.

## Что нужно

- Windows 10 или 11 (64-бит), 8 ГБ памяти, 2 ГБ свободного места на диске.
- **Node.js 24** (https://nodejs.org, версия 24 LTS), если он ещё не установлен.
- Папка проекта целиком (`D:\optomstroy`), а не только папка `demo`. Демо уже собрано: приложение лежит в `demo\app`.
- Компьютер должен быть подключён к сети (Wi-Fi или кабель), интернет не обязателен. Если сети нет совсем, приложение покажет «Нет сети».

Если в `demo\app` нет приложения, демо нужно собрать. Это делает программист, и на компьютере должны быть Flutter и Visual Studio (C++). Откройте PowerShell и выполните:

```
powershell -ExecutionPolicy Bypass -File D:\optomstroy\demo\build-demo.ps1
```

Сборка идёт 5–15 минут. Если папку демо перенесли в другое место, сборку нужно повторить.

## Как запустить

1. Дважды щёлкните **`demo\start-demo.cmd`**.
2. Откроется чёрное окно. Первые 1–3 минуты запускается сервер и загружаются тестовые данные, на экране идут точки.
3. Затем откроется окно приложения «Оптомстрой». Чёрное окно не закрывайте, пока работаете.

Если Windows спросит разрешение для Node.js в брандмауэре, можно нажать «Отмена»: демо работает только внутри этого компьютера.

## Учётные записи

Чтобы войти, введите номер телефона и код **246810**. Если ввести свой номер, приложение зарегистрирует вас как нового покупателя (имя, год рождения, защита входа). Номера из таблицы ниже — готовые сотрудники с ролями.

| Номер | Кто это |
|---|---|
| +996 777 000 901 | Администратор |
| +996 777 000 902 | Продавец (приглашён администратором, «Тестов Продавец») |
| +996 777 000 906 | Кассир |
| +996 777 000 907 | Старший продавец |
| +996 777 000 909 | Руководитель |
| +996 777 000 905 | Новый покупатель (регистрируется сам) |
| +996 777 000 903 | Ещё один новый покупатель |
| +996 700 123 456 | Покупатель, у которого уже есть карточка в 1С (Асанов Бакыт) |

- **Сотрудник** при первом входе сам придумывает **PIN из 6 цифр**, например 715382. Простые PIN вроде 111111 или 123456 не подойдут. Потом этот PIN нужен, чтобы подтверждать важные действия.
- **Покупатель** при первом входе заполняет короткую анкету (имя, год рождения) и задаёт PIN из 4 цифр.
- Номер +996 777 000 904 никому не назначен. Администратор может пригласить на него нового сотрудника.
- Любой другой номер +996 тоже принимает код 246810: приложение зарегистрирует его как нового покупателя.

Тестовые клиенты. Кассир, старший продавец, администратор и руководитель находят их по имени или по последним 4 цифрам телефона. Продавец ищет только по полному номеру (например, +996 700 223 344): так задумано (ядро §19.4).

| Клиент | Телефон | Что с ним проверить |
|---|---|---|
| Асанова Айгуль | +996 700 223 344 | Есть просроченный долг, продажа в долг запрещена |
| Асанов Бакыт | +996 700 123 456 | Долг в пределах лимита, продажа в долг разрешена |
| ОсОО «Лимит-Строй» | +996 555 000 104 | Кредитный лимит превышен |
| ОсОО «Чистый Дом» | +996 555 000 103 | Долгов нет |

## Что попробовать

1. **Продавец: продажа с оплатой по QR** (+996 777 000 902).
   Каталог → поиск товара, фото и остатки → «+ Добавить» два-три товара → кнопка «Корзина» в шапке (можно дать скидку до 5 %) → «Создать заказ · F9» → в окне «Подтверждение заказа» «Самовывоз» и «QR / карта Бакай Банк» → «Создать заказ и показать QR». Появится QR-код для оплаты. Примерно через 10–20 секунд приложение покажет «Оплата получена». Затем откройте «Товарный чек»: «Открыть заказ» → «Документы» → «Товарный чек» → «Просмотр». Это PDF с предпросмотром, чек нефискальный.

2. **Кассир: продажа в долг заблокирована** (+996 777 000 906).
   Клиенты → найдите «3344» (Асанова Айгуль) → в карточке видно долг и просрочку → «В заказ» → добавьте товар → кнопка «Корзина» → «Создать заказ · F9» → «Без оплаты / долг». Приложение не даст продать в долг и покажет причину: «Есть просроченная задолженность». Там же есть подсказка «Как получить разрешение старшего». Тот же заказ можно создать за наличные: «Наличными в кассу» → «Создать заказ». Затем отметьте, что деньги получены: «Принять оплату» → «Подтвердить приём».

3. **Старший продавец: разрешение продажи в долг** (+996 777 000 907).
   Выйдите из кассира и войдите старшим продавцом. В корзине выберите клиента Асанову Айгуль → «Создать заказ · F9» → «Без оплаты / долг» → «Разрешить продажу в долг» → укажите причину и подтвердите своим PIN → «Создать заказ в долг». Заказ создаётся в долг. Для сравнения у клиента Асанов Бакыт (долг в лимите) продажа в долг проходит сразу, без разрешения.

4. **Покупатель: заявка из приложения** (+996 777 000 905).
   Регистрация (имя, год рождения, PIN) → каталог с ценами → «+ Добавить» → корзина → «Отправить заявку» → «Мои заказы»: заявка в списке. Если войти с номером +996 700 123 456, приложение предложит привязаться к карточке 1С («Да, это я»). После этого покупатель видит свой долг.

5. **Администратор: пользователи и аудит** (+996 777 000 901).
   «Администратор» → «Пользователи» → список сотрудников и их роли → «+ Пригласить» сотрудника на номер +996 777 000 904. После этого можно войти с этим номером: учётная запись появится сама. «Журнал аудита» (меню разделов «☰») → журнал действий. После сценария 3 там видна запись «Разрешена продажа в долг».

6. **Руководитель: отчёты** (+996 777 000 909).
   Главный экран → «Отчёты». Здесь продажи за сегодня, средний чек и долги клиентов. Цифры учитывают заказы, оформленные в предыдущих сценариях.

7. **Работа без сети.**
   Войдите продавцом и откройте каталог. Затем отключите Wi-Fi (или включите режим «в самолёте», или выньте кабель). Приложение покажет «Нет сети». Каталог открывается из памяти, изменения корзины сохраняются и уйдут на сервер, когда сеть вернётся. Оплата и оформление заказа без сети недоступны, и приложение честно об этом говорит. Включите сеть: баннер пропадёт, данные досинхронизируются.

## Ограничения демо

- Тестовые данные. Это не реальные товары, цены, клиенты и долги магазина.
- Нет реальной 1С, SMS и банка: их заменяют имитаторы. Связь с настоящей 1С проверяется отдельно, когда программист 1С подготовит доработку.
- Всё работает на одном компьютере. Телефоны и другие компьютеры к этому демо не подключаются.
- После каждого перезапуска данные создаются заново.
- Печать на принтер чеков не настроена, чеки показываются как PDF.

## Где журналы

Всё лежит в папке `demo\logs`:

- `start-demo.log`: что выводилось в чёрном окне;
- `server.log`, `server.err.log`: журнал запуска сервера;
- `stack\api.log`, `stack\worker.log`, `stack\fake-onec.log`: подробные журналы сервера, фоновых задач и имитатора 1С (появляются после остановки демо);
- `smoke.log`, `smoke.png`: результат самопроверки (см. ниже).

Если что-то пошло не так, пришлите программисту папку `demo\logs` целиком. Паролей и секретов в ней нет, только тестовые значения демо.

## Как остановить

- **Закройте окно приложения.** Демо само остановит сервер и напишет «Демо остановлено».
- Если чёрное окно осталось открытым с сообщением об ошибке, нажмите любую клавишу.
- Если что-то зависло, закройте чёрное окно крестиком. При следующем запуске демо само остановит остатки прошлого запуска и освободит порты.

## Для программиста

- `start-demo.cmd -NoApp`: только сервер (`http://127.0.0.1:8080/api/v1`), Enter останавливает.
- `start-demo.cmd -Smoke`: самопроверка. Поднимает сервер, проверяет `/health/ready`, вход кассира по коду 246810 и каталог, запускает приложение на 25 секунд, делает снимок окна в `demo\logs\smoke.png`, всё останавливает и пишет «SMOKE OK» или «SMOKE FAIL» (код выхода 0 или 1).
- `start-demo.cmd -KeepAppData`: не очищать данные приложения (`demo\data`) перед запуском.
- Используемые порты: 3000 (API), 8080 (мини-прокси: API и фото), 8091 (имитатор 1С), 8092 (управление стендом). PostgreSQL получает свободный порт и хранит данные в `demo\.tmp`.
