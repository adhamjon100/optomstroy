# Тексты согласий и информирования (ru) — версии и хэши

Статус: **ПРОЕКТ для юриста заказчика** (Q-027, O-08). Источник формулировок — шаблоны 1–3 из
`docs/specification/11_SECURITY_PRIVACY.md` §10.3. Плейсхолдеры `<…>` заполняет заказчик; после заполнения каждый
изменённый текст получает **новую версию** (старые записи `consents` остаются со своей версией и хэшем).

## Правила

- Вид — значение `consent_kind` (07 §6.1): `personal_data`, `sms`, `biometrics_device`, `activity_sphere`
  (`face_scan` — R2, текста здесь нет; значение `biometric_unlock` не используется).
- `version` — строка `YYYY-MM-DD`; сервер принимает только **текущую** версию вида (08 §4.2.1, §4.3.7).
- `sha256` — SHA-256 (hex, нижний регистр) байтов UTF-8 текста из блока ```` ```text ```` ниже, с концами строк
  LF и без начальных/конечных пустых строк. Значение пишется в `consents.text_sha256` (07 §5.14, DATA-113):
  доказательство того, какой именно текст был показан.
- Каталог версий в коде — `pos-api/src/profile/consents/consent-catalog.ts`; тест
  `pos-api/test/profile/consent-catalog.profile-spec.ts` сверяет версии и хэши этого файла с каталогом.
- Новая версия текста: добавить раздел с новой `version`, пересчитать `sha256`, обновить каталог (поле `current`);
  прежний раздел не удалять (доказуемость ранее выданных согласий).

## personal_data — версия 2026-10-01

- kind: `personal_data`
- version: `2026-10-01`
- sha256: `694422aa0afe21bb1d9f237607d80feb66ae34e406a298fb942cafc909ecdaff`
- Экран: SCR-03 (ключ ARB `register_consent_pd_text`), отметка «Я ознакомлен(а)»; для сотрудника — при первом
  входе (SCR-04, `POST /me/consents`). Запись — факт **информирования**, а не согласие по ст. 79 (основание
  обработки — договор / законный интерес, 09 §7.1).

```text
Оператор (владелец записей): <полное наименование магазина, ИНН, адрес, контакт ответственного за персональные данные>.
Цели: создание учётной записи и вход по номеру телефона, оформление заказов, взаиморасчёты, обеспечение безопасности.
Данные: номер телефона, фамилия, имя, отчество, год рождения (для идентификации при обращениях и восстановлении доступа), идентификатор устройства, технические данные сессии.
Основание: исполнение договора (условий работы с магазином) и законные интересы оператора по обеспечению безопасности (ст. 79 Цифрового кодекса КР).
Срок: период использования учётной записи и до <N> лет после — в части, необходимой для бухгалтерского учёта.
Права: доступ, уточнение, удаление (с ограничениями ст. 83), возражение, ограничение обработки, отзыв согласия — через раздел «Профиль → Персональные данные» или по контакту ответственного.
Передача: данные хранятся на сервере в Кыргызской Республике; передача за пределы КР не осуществляется.
Нажимая «Продолжить», вы подтверждаете, что ознакомлены с этой информацией.
```

## activity_sphere — версия 2026-10-01

- version: `2026-10-01`
- sha256: `6f3d12af9ce83662f520ff51e210861da25f54081bab4716cc492ad782882f39`
- Экран: SCR-03, отдельный невыбранный чекбокс рядом с полем «Сфера деятельности» (UI-03-015). Необязательное
  согласие; без него поле `activitySphere` не передаётся и не хранится; при отзыве `user_profiles.activity_sphere`
